# 5W2H 需求拆解

来源：[[04-需求分析：接到需求，以Agent视角进行分析和结构设计#3. 5W2H：把一句话需求拆成 7 个维度]]

5W2H 用来把一句模糊需求拆成 7 个可回答的问题：

| 维度 | 问什么 |
|---|---|
| Why | 为什么做：目的、价值 |
| Who | 为谁做：用户、对象 |
| What | 做什么：范围、内容 |
| When | 何时/何场景：触发时机 |
| Where | 在哪用：渠道、入口 |
| How | 怎么做：形态、方式 |
| How much | 投入多少：成本、资源 |

课程里的拆解路径：

`一句话需求 → 5W2H 提问 → Agent 四问 → 需求结构图`

注意：5W2H 不是填表，而是逼自己把目标、范围、资源、路径和边界讲清楚。
