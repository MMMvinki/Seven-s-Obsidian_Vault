# AI 产品五层结构

来源：[[04-需求分析：接到需求，以Agent视角进行分析和结构设计#14. 产品设计：五层结构与五个要素]]

课程把 AI 产品结构拆成五层：

| 层级 | 产品经理要关注什么 |
|---|---|
| 用户层 | 用户体验、提问入口、能不能拿到需要的答案并完成动作 |
| 提示词/应用层 | Prompt 结构化、回答确定性、可控性 |
| 应用能力层 | RAG、Function call、MCP、接口、知识库、评测 |
| 模型层 | 准确性、易用性、成本、垂直能力 |
| 数据层/算力层 | 数据是否丰富可靠，是否适合被模型和系统调用 |

落到 AI 客服时，可进一步拆成五个要素：

`接入 → 理解 → 决策 → 能力 → 兜底`

其中“理解”负责意图识别和信息提取，“决策”负责路由，“能力”负责 RAG/接口/话术生成，“兜底”负责转人工。
