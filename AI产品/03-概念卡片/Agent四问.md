# Agent 四问

来源：[[04-需求分析：接到需求，以Agent视角进行分析和结构设计#2. Agent 四问：目标、能力、知识、边界]]

Agent 四问是把 AI 产品需求从“功能清单”拆成“可执行系统”的框架：

| 四问 | 解释 | AI 客服例子 |
|---|---|---|
| 目标 Goal | 它必须达成什么结果 | 自助解决 60% 售后咨询，降低人力成本 |
| 能力 Capability | 它必须会做什么 | 意图识别、知识检索、接口调用、转人工 |
| 知识 Context | 它靠什么回答 | 政策、商品文档、订单系统、历史工单 |
| 边界 Boundary | 它不能做什么 | 投诉、退款、低置信、情绪激动转人工 |

复习时直接背：

> AI 产品需求分析要切 Agent 视角：目标、能力、知识、边界。

工作使用场景：接到“做个 AI 助理/AI 客服/AI 工具”这类一句话需求时，先用 Agent 四问把它拆清楚，再进入流程和功能设计。
