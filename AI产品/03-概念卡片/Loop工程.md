# Loop 工程

> 来源章节：[[07-提示词设计：场景拆解，构建Prompt#4. Loop 工程：让 AI 自动持续推进|Loop 工程]]

## 一句话定义

Loop 工程让 AI 不只执行一次，而是能根据结果继续判断、修正、重试、推进下一步。

## 典型结构

1. 执行：模型生成或判断。
2. 检查：模型或规则检查结果是否达标。
3. 修正：不达标则补充信息、重写、重试。
4. 继续：达标后进入下一个节点。

## 和 Prompt 的关系

Loop 不是替代 Prompt。每个循环节点依然需要 Prompt 来规定它的角色、输入、输出、限制和终止条件。

## 复习提醒

当任务复杂到“写一次不一定对”，就要考虑 Loop，而不是继续把一个 Prompt 写得更长。
