# Vibe Coding

来源：[[05-demo搭建：用Vibe Coding构建产品Demo#4. Vibe coding 是什么]]

Vibe coding 是一种“描述需求、AI 帮你写代码”的方式。

核心流程：

`设计 → 描述 → 生成 → 预览 → 迭代 → 部署`

老师强调的关键不是“不会代码也能做”，而是：

> ==Vibe coding 省掉的是代码，不是设计。==

使用场景：

- 快速做产品 Demo。
- 把 Coze / Agent 后台逻辑包装成可演示界面。
- 面试或汇报时展示“我能把想法落成东西”。

常见误区：

- 直接说“做个客服网页”，AI 全靠猜。
- 一次塞太多功能。
- 不给示例数据。
- 不写技术约束，导致代码复杂、难部署。
