# Agent 需求澄清 Checklist

来源：[[04-需求分析：接到需求，以Agent视角进行分析和结构设计#2. Agent 四问：目标、能力、知识、边界]]

接到一句模糊 AI 需求时，按下面问题问一遍：

| 维度 | 问题 |
|---|---|
| 目标 | 最终目的是什么？成功怎么衡量？ |
| 用户 | 主要给谁用？C 端用户、内部员工、运营、客服还是主管？ |
| 场景 | 什么入口、什么情况下使用？ |
| 范围 | 第一版先覆盖哪些问题？哪些明确不做？ |
| 数据 | 有哪些现成知识、文档、系统或历史数据？质量如何？能用吗？ |
| 边界 | 哪些情况必须人工介入？红线在哪？ |
| 资源 | 预算、人力、上线时间是多少？ |
| 衡量 | 上线后用什么指标判断好坏？ |
