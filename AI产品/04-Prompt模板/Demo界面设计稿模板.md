# Demo 界面设计稿模板

| 维度 | 内容 |
|---|---|
| 产品 | [产品名称 + Demo 类型 + 设备] |
| 区域 | [顶部栏 + 主内容区 + 输入区等] |
| 组件 | [按钮 / 卡片 / 气泡 / 提示条 / 输入框] |
| 状态 | [空 / 加载中 / 正常 / 转人工 / 出错] |
| 交互 | [点击、输入、回车、滚动、加载、错误提示] |
| 风格 | [配色、圆角、留白、字体、参考对象] |
| 数据 | [3-4 条真实业务示例] |
| 范围 | [只做什么，不做什么] |

设计原则：

> 设计稿越具体，提示词越好写，AI 越不用猜。
