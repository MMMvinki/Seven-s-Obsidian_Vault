# Demo 验收 Checklist

## 价值闭环

- [ ] 能打开公开链接。
- [ ] 能输入问题。
- [ ] 能看到像样回复。
- [ ] 能体现核心流程。
- [ ] 有转人工或兜底提示。
- [ ] 老板/用户能看懂它解决什么问题。

## 提示词质量

- [ ] 先说做什么产品，再说功能。
- [ ] 界面按模块拆开描述。
- [ ] 给了真实示例内容和数据。
- [ ] 指定了风格：配色、调性、参考对象。
- [ ] 写清交互细节：发送、加载、空态、错误。
- [ ] 设计了多种状态。
- [ ] 划定技术约束。

## 联调部署

- [ ] 公开链接可访问。
- [ ] Token 不写死在前端。
- [ ] Coze 工作流已发布 API。
- [ ] 入参、出参清楚。
- [ ] 失败状态有提示。
- [ ] 一处处把 Mock 换成真实调用。
