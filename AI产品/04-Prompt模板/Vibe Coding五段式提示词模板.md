# Vibe Coding 五段式提示词模板

## 模板

```text
你是一名前端工程师，帮我做一个网页 Demo。

【产品】
[说明这是一个什么产品，用来解决什么问题]

【界面】
[说明平台：桌面端/手机端]
[说明区域：顶部栏 / 消息区 / 输入区 / 其他模块]
[说明组件：按钮、气泡、提示条、输入框等]

【风格】
[配色]
[圆角/留白/字体/质感]
[参考对象：像微信客服/Apple/Linear 等]

【示例数据】
[给 3-4 条真实业务示例]

【交互】
[回车发送、加载状态、自动滚动、错误提示、转人工等]

【技术约束】
[单页/React/HTML/假数据/不要登录/代码简单好改]
```

## 课件示例

```text
你是一名前端工程师，帮我做一个网页 Demo。

【产品】
零食电商的 AI 客服聊天页，帮用户查物流、问退换货政策。

【界面】
桌面端单页，分三部分：
- 顶部：标题栏“零食小助手” + 绿色在线状态点。
- 中间：消息区，AI 消息靠左、浅色气泡；用户消息靠右、暖色气泡。
- 底部：输入框 + 圆形发送按钮。
- 顶部放 3 个常见问题按钮。

【风格】
暖色调（米色背景 + 橙棕点缀），圆角，留白，像微信客服一样亲切。

【示例对话】
用户：我买的沙发到哪了？
AI：您的订单 86731 已到本地仓，预计明天送达~

用户：怎么退货？
AI：支持 7 天无理由退货，我帮您发起~

【交互】
回车发送；发送后清空输入框；自动滚到底部；回复前显示“正在输入…”约 1 秒。

【技术】
单页 React，用写死的假数据，不接后端，代码简单好改。
```
