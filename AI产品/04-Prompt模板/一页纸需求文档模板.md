# 一页纸需求文档模板

来源：[[04-需求分析：接到需求，以Agent视角进行分析和结构设计#9. 一页纸需求文档：给老板看的第一份东西]]

课件说：把结构图浓缩成一页文字，这就是给老板看的第一份东西。

| 模块 | 写法 |
|---|---|
| 项目名称 | [业务/场景] · [AI 产品]（一期） |
| 背景/目标 | [为什么做]；目标 [核心指标] |
| 目标用户 | [主用户]；[辅助用户] |
| 核心场景 | [第一版覆盖的高频场景] |
| 关键能力 | [意图识别 / RAG / 接口 / 生成 / 转人工等] |
| 第一期不做 | [明确边界，避免范围扩张] |
| 衡量指标 | [自助解决率 / 转人工率 / 满意度 / 响应时长等] |
| 资源/排期 | [人力、工具、Demo 时间、上线时间] |
