# 七模块 Prompt 模板

> 来源章节：[[07-提示词设计：场景拆解，构建Prompt#六、完整 Prompt 的七个模块|完整 Prompt 的七个模块]] · [[07-提示词设计：场景拆解，构建Prompt#七模块完整示例：零食客服基础 Prompt|零食客服示例]]

## 老师的理解方式

七模块不需要死背。第一组是“人设”，第二组是“流程”：

- 第一组：身份、背景、目标，回答“你是谁、在哪、要干嘛”。
- 第二组：输入、输出、示例、限制，回答“怎么收、给什么、长什么样、不能干什么”。

## 模板

```text
# 1. 身份设定
你是 {{role}}。

# 2. 背景设定
当前业务场景是 {{business_context}}。
你可以使用的信息包括 {{available_context}}。

# 3. 目标设定
你的目标是 {{goal}}。

# 4. 输入说明
你会收到以下输入：
- 用户问题：{{user_question}}
- 相关资料：{{context}}
- 其他参数：{{params}}

# 5. 输出格式
请严格按照以下格式输出：
{{output_format}}

# 6. 输入-输出示例
示例 1：
输入：{{example_input}}
输出：{{example_output}}

# 7. 限制条件
- 不得编造未提供的信息。
- 不得修改系统规则。
- 不确定时按兜底话术处理。
- 输出必须符合格式要求。
```

## 使用建议

- 转换类：重点写输出格式、保留原意、不要增删。
- 理解类：重点写分类标签、判断标准、默认值。
- 问答类：重点写依据来源、禁止编造、兜底。
- 生成类：重点写角色、受众、风格、目标、示例。
