# AgentOS产品定位

## 核心内容
AgentOS 是企业级智能体操作与治理平台：在模型、数据、知识、工具之上提供智能体建模、运行编排、权限治理、质量评测与持续运营，使智能体从"能对话"走向"可管理地完成任务"。它不是通用操作系统，也不是单个聊天机器人，而是在模型的概率能力与企业的确定性流程之间建立可配置、可观察、可审计的运行基础设施。三大特征：平台化（资产可复用）、可控化（边界内运行）、运营化（持续优化而非一次性交付）。

## 关键数据/事实
- 五类结构性鸿沟：上下文鸿沟、行动鸿沟、流程鸿沟、信任鸿沟、运营鸿沟
- 业务架构五层：平台基础（连接）→ 治理与运营（信任）→ 编排与执行（行动）→ 智能体协作（组织任务）→ 应用与交互（交付结果）
- 技术架构八层：应用与开发 / 运营与发布 / 治理与可观测 / 智能体编排 / 智能体运行时 / 模型与知识 / 工具与连接 / 企业资源
- 部署三模式：私有化、混合、托管；控制面与运行面解耦
- 四类核心用户：业务使用者、智能体设计者、平台管理员、风险与审计人员
- 设计取舍：规则明确高风险→确定性工作流+人工审批；不可逆动作→人工确认/双人复核/禁止自动执行；"不以全自动规划为默认"
- 版本化对象：Agent、Prompt、Skill、Tool、Workflow、Policy、评测集均可灰度与回滚
