# DataOS功能模块

## 来源
- raw/DataOS 技术白皮书.md（第四章 4.1–4.7）

## 核心内容
DataOS 白皮书第四章定义了七大功能模块：数据源管理（连接器框架，多类型数据源统一纳管）、数据治理（质量规则+任务调度+标准化）、本体建模（核心，见独立笔记）、图谱关系（知识图谱可视化与路径查询）、审计血缘（全链路血缘+影响分析+审计日志）、日志管理（操作/登录日志+异常检测）、系统管理与监控（多租户 RBAC 八项管理能力）。模块间形成"接入→治理→本体→服务"的完整数据流转链路。

## 关键数据/事实
- 数据源支持：关系库（MySQL/PostgreSQL/Oracle）、时序库（InfluxDB/TimescaleDB）、数仓（StarRocks/ClickHouse）、API、文件、IoT/音视频流、SaaS/ERP
- 质量检查四类：完整性（非空）、一致性（枚举范围）、准确性（数值范围）、及时性（更新频率）；支持自定义 SQL 规则
- 数据流出本体建模的四条路径：图谱可视化、自动 API 生成（GraphQL/REST，权限自动继承）、工作流编排（Temporal）、智能体调用
- 审计血缘基于 DataHub 自动解析 SQL/ETL/API 调用关系；血缘存 PostgreSQL + AGE 图查询
- 系统管理：租户/用户/部门/岗位/角色/菜单/字典/监控 八项，RBAC 用 Keycloak+OPA
- 大模型辅助接入：根据数据源特征智能推荐方案、自动生成接入配置和 ETL 流程
