# 三项核心立论与Workshop

## 来源
- raw/爱化身企业级AI对客战略与全域转型服务总纲_V1.3_20260803_副本.md（第四部分·二十一至二十八）

## 核心内容
对客叙事先完成三项立论再谈场景细节：第一立论·认知基础——为什么必须以本体为基础（只有把对象、关系、规则、血缘和因果建模，AI 才能形成稳定企业认知、降低幻觉）；第二立论·运行机制——为什么必须全域集群智能（局部 Agent 不共享语义与治理只会形成新的 AI 孤岛）；第三立论·价值落点——为什么必须进入真实经营场景形成闭环（感知-判断-执行-反馈-优化，以经营结果衡量）。叙事原则"内部强逻辑，外部强故事"。销售能力标准：4 小时内给出可见产品原型，不能连续多轮只讲 PPT。

## 关键数据/事实
- 首次会面 60-90 分钟结构：0-10 战略问题 / 10-25 三项立论 / 25-45 实操 Demo / 45-65 经营体系映射与首发闭环假设 / 65-90 讨论与下一步
- 原型时效标准：前端概念原型 4 小时、当天闭环演示版当天、A/B/C 首发方案 1-3 天、单域 DataOS 验证 2-3 天、结构化数据 POC 原则上一周内
- 八类常见异议标准回应：已有北森/Moka/飞书机器人、"先做一个 Agent 看看"、"我们自己也能做"、是否都从 HR 开始、创业公司会不会消失、案例不够多、数据安全、报价多少（Workshop 当场不报价）
- 每个原型必须明确证明哪项立论、服务哪个经营对象、如何接入后续经营闭环，"不得形成一次性漂亮页面"
- 按三类行业建立模拟数据集 + HR 等首发场景的任务库/范例库/教学案例库；销售必须会实际操作 DataOS
