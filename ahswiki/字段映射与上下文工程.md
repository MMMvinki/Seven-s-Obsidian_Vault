# 字段映射与上下文工程

## 来源
- raw/DataOS答疑相关 20260603.md（维度三、八）

## 核心内容
解决"数据量太大、上下文有限、模型会变傻"的两个核心做法。字段映射（钱总补充的关键点）：把几千上万个晦涩字段用自然语言映射成语义节点，多对一/多对少地"升维"成一张语义网，语义网下面才是数据字段——直接把数据库做成图丢给模型当 RAG 会"把 context 占爆"，实验证明不现实。上下文工程两板斧：知识切片+渐进披露（切成领域知识块，块间带渐进式关系，像 Skill 一样先给渐进包，顺关系再取下一块）；多层调度 Agent 集群（树形 agent 把大任务切分，每个 agent 只在自己知识切片里调研、向上汇报）。

## 关键数据/事实
- 切片思路类比 Anthropic 的上下文管理方法，扩展为"文件系统式的知识组织"
- 单个 agent 解决不了大规模复杂任务，"必须靠集体策略"
- 该思路与 Skill 机制衔接：上传时像 Skill 一样先给渐进式包，不是一次性全扔进上下文，也不是简单检索
- "强关系、渐进披露，理解效率很高"
