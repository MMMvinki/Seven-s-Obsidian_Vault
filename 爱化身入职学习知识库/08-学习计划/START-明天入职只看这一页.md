# 明天入职只看这一页

返回 [[00-爱化身入职学习地图]]。

**没有读完知识库，不等于没有能力上岗。**前面的教材是长期参考资料，其中部分深入内容超出了入职前优先级。现在用这页明确边界；今晚准备30分钟，剩下的问题带到真实工作里验证。

下面的深度依据[[AI Native 售前技术专家_岗位详情.txt]]与面试记录推导，是岗位成长目标，不是公司要求你明天全部通过的考试。

## 1. 这个岗位需要懂到哪里

记住三个标准：**能讲清、能拆方案、能做小验证。**涉及大规模部署、复杂集成或底层算法时，能指出关键依赖，整理问题请FDE/产品/研发评估。

| 内容 | 工作中应掌握的深度 | 具体做到什么 |
|---|---|---|
| 公司产品与三层架构 | 能独立讲清价值、职责、已确认的能力边界 | 用一个业务例子讲Data OS、Agent OS、Workforce；不确定的版本功能找产品确认 |
| 本体与数据建模 | 能画草图、做简单映射和验证 | 写出道路、车辆、班组、工单；说明它们的关系、状态、来源与派单规则 |
| RAG、Agent、工具、MCP | 能解释机制、适用条件与常见失败 | 知道查条款、查车辆状态、创建工单分别依赖什么；基本链路能搭建或复现 |
| API、SQL、AI Coding | 有实际动手能力，能读懂关键代码和定位常见错误 | 在熟悉的一套技术栈中接接口、查数据、做界面、跑通演示，处理空数据和调用失败 |
| 客户沟通、Demo、轻量POC | 逐步能独立组织和主导 | 问清使用人、问题、数据、范围和验收；展示一条有结果的流程 |
| 生产架构、模型训练、复杂优化 | 理解为什么需要、主要风险和验证方式；协同深入实现 | 发现权限、重复派单、资源冲突、专网部署等问题，带具体证据请技术团队评估 |

“能借助AI做出来”符合JD的工具使用要求，但需要你能说明输入输出、关键逻辑、错误和验证方式。能生成代码却完全不知道它做了什么，会成为需要补齐的实际缺口。

## 2. 用本体举例，看什么叫深度够用

客户说：“发现路面垃圾，就派最近的车。”

能给出以下说明，就在接近岗位需要的应用深度：

- 对象：道路、垃圾事件、车辆、班组、工单。
- 关系：事件发生在哪段路，路段由谁负责，车属于哪个班组。
- 规则：车辆要有对应能力、在班、空闲，位置要新鲜，并且具有该区域的调度权限。
- 动作：提出候选，按授权审批，创建工单，跟踪接单与完成。
- 验证：最近的车忙了、位置过期或跨区时，系统应该怎样处理？

入职前不以能否实现OWL推理器为标准。你需要把业务语义解释清楚并做简单建模；复杂推理由团队一起设计。下一步最有价值的是看公司平台如何实现这五件事。

## 3. 明天最重要的三件事

**确认第一个月的期望。**可以说：“我想把学习和实际任务对齐，第一个月最希望我独立完成哪些事情？产品讲解、Demo和POC有没有成熟例子可以参照？”

**找到一个成熟样例和对接人。**请同事带你完整看一次产品演示，了解数据怎么进入、对象怎么建、工具怎么调、结果如何验证；同时明确产品、FDE和销售分别找谁。

**用一个小任务形成学习闭环。**例如复现已有Demo，改一个字段映射，或补一段客户讲解。记录问题、验证、结论。首周重点从读懂资料转到熟悉真实产品，而不是继续堆术语。

## 4. 今晚30分钟，只做这些

**10分钟：**读下面的四句话，尝试自己复述。

1. Data OS：把分散数据组织成有业务含义、可追溯的对象和关系。
2. Agent OS：组织工具、Agent和流程，让任务在明确的权限与状态下运行。
3. Workforce：把这些能力落实到具体岗位、SOP和可衡量的任务结果。
4. 本体：说明业务里有什么、相互怎样关联、适用哪些规则，帮助系统按业务语义工作。

**10分钟：**用UrbanScope准备一个简短说明：“我做过什么、现场能展示什么、目前局限是什么。”已有真实经验比临时背十个术语更能支持交流。

**10分钟：**写下明天的三个确认问题和自己最不懂的三个点，然后结束学习。复杂公式、协议细节和完整部署章节留到相关任务出现时查阅。

## 5. 被问到不会的内容，可以这样答

“这部分我目前理解到业务和应用层，具体到我们这个版本的实现还需要确认。我先把场景和要求记清楚，找产品/FDE核实后，再给一个准确的答复。”

随后补上你已知的拆解：“我看主要涉及数据接入、规则和执行权限三个部分，目前不确定的是……”这样同事能接住问题，客户也知道下一步是什么。

不用向每个人解释自己“很虚”，可以具体说“这一块还没操作过，需要先看一个例子”。具体缺口可以补，笼统否定自己不能帮助工作。

## 6. 第一周怎么判断进步

每天记录三句话：今天弄懂了哪项真实产品能力；独立完成了哪个小任务；还有什么问题、向谁确认。每周和主管核对一次进展与优先级。学习目标以岗位实际任务为准，不以读完36篇笔记为准。
