# 入职首月行动清单

## P0：立即确认

- [ ] 确认已加入 AI Native、销售分享、早会及相关业务群。
- [ ] 收齐负责人承诺的内部资料、技术答疑册、历史对客材料和优秀案例。
- [ ] 确认第一项真实任务、截止时间、验收人和可调用资源。
- [ ] 向 HR/负责人确认六个月试用期正式考核表、评价人和复盘节点。
- [ ] 确认哪些内部或客户信息允许进入个人 Obsidian，哪些必须留在公司系统。

## 第一周：把公司讲明白

- [ ] 完成平台全流程演示，记录每一步的业务含义。
- [ ] 用自己的话讲清 DataOS、AgentOS、本体、RAG 的关系。
- [ ] 画出数据接入—清洗—实体/对象—关系—动作—Agent 的链路。
- [ ] 梳理目标客户画像、业务推进流程和经营面切入逻辑。
- [ ] 精读 2—3 份优秀对客材料，提炼叙事结构和语言质感。
- [ ] 找一位同事进行 10 分钟模拟讲解，收集具体反馈。

## 第二周：选择行业并建立经营认知

- [ ] 与负责人确认首个行业/项目，不凭个人兴趣单方面锁定方向。
- [ ] 建立行业经营地图：客户、业务、收入、成本、风险、核心指标。
- [ ] 梳理行业对象、关系、事件、规则和动作。
- [ ] 找出 3—5 个 AI 切入点，并按价值、可行性、数据条件排序。
- [ ] 向行业同事或真实业务人员校验模型调研结果。

## 第三周：做出可展示的闭环

- [ ] 确定一次演示要帮助客户做出的唯一决策。
- [ ] 完成一个主链路，明确真实数据、模拟数据和待开发能力。
- [ ] 把功能介绍改写为经营价值和未来图景。
- [ ] 准备 CEO 版 3 分钟讲解、业务版 10 分钟讲解和 CTO 追问清单。
- [ ] 设计断网、接口失败、数据为空或参数波动时的备用路径。

## 第四周：开始会客并形成闭环

- [ ] 参加一次真实客户会议，明确自己是旁听、辅助还是主讲。
- [ ] 会前整理客户画像、参会人、经营问题、展示目标和可能异议。
- [ ] 会中记录客户原话、决定事项、承诺和未解决问题。
- [ ] 会后 24 小时内形成纪要、责任人、时间和下一步。
- [ ] 把会议反馈用于修订方案，并记录修订原因。
- [ ] 与负责人做首月复盘，对齐接下来 60 天目标。

## 首月最小成果包

- [ ] 1 张公司业务与产品总图；
- [ ] 1 份行业经营地图；
- [ ] 1 个可演示的行业主链路；
- [ ] 1 份有叙事的 HTML 方案；
- [ ] 1 套会客准备与会后纪要；
- [ ] 1 个可复用的 Skill、Prompt、组件或问答资产；
- [ ] 1 次来自负责人或资深同事的明确反馈。

## 向负责人同步的简短格式

> 本周围绕【目标】完成了【成果】，目前已经能够【可观察能力】。其中【事实/数据】已核验，【假设/目标能力】仍待确认。下一步准备推进【最重要事项】，需要【人员/资料/技术】支持，请您确认优先级是否正确。
